# Benchmarks — deliberately empty in v0.1

This directory is reserved for **validated, documented, privacy-reviewed reference distributions**.

ReadyGap v0.1 has **no** legitimate global peer percentiles or rankings. We must not populate this directory with synthetic "global averages," inferred user comparisons or unconstrained self-selected questionnaire statistics presented as population norms.

Before adding an actual benchmark:

1. Define reference population, entity type, sector, language, sampling frame and time period.
2. Obtain explicit data-use rights, consent and privacy protection; do not publish identified workflow/task data.
3. Specify item/scoring versions, missingness and coverage denominator rules.
4. Test scale comparability and systematic measurement bias, including person/team/company differences.
5. Include sample count, uncertainty intervals and limitations alongside each published statistic.

Until these conditions are met, report only **absolute self-reported scores**, domain profiles and activity bottlenecks.
